# 📊 Data Analysis Portfolio

### 📊 Power BI Employee Analytics Dashboard
Interactive HR analytics dashboard developed in Microsoft Power BI to explore workforce demographics, employee distribution, attrition patterns, and compensation data using Power Query, DAX, and interactive visualisations.

One page sales analysis report developed using Microsoft Power BI to explore sales performance, profitability, customer segments, regional distribution, and product sub-categories through KPI cards and visualisations. Completed as a guided learning project.
