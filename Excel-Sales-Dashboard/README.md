# 📊 Sales Performance Dashboard

## Project Overview

This project is an interactive Microsoft Excel dashboard developed to analyse global sales performance. The dashboard transforms raw sales data into meaningful business insights using PivotTables, Pivot Charts, KPI cards, and interactive slicers.

It enables users to explore sales performance across different markets, regions, customer segments, product categories, and order priorities.

## Objectives

- Analyse overall sales performance.
- Monitor key business metrics using KPI cards.
- Compare sales and profit across different markets and regions.
- Identify trends by customer segment and product category.
- Build an interactive dashboard for business decision-making.

## Tools Used

- Microsoft Excel
- PivotTables
- Pivot Charts
- Slicers
- KPI Cards

## Key Insights

- Asia Pacific recorded the highest sales.
- Consumer segment generated the largest share of sales.
- Technology and Furniture were among the strongest-performing categories.
- Interactive slicers allow users to analyse performance by Market, Region, Segment, Category and Order Priority.
