# 📊 Employee Analytics Dashboard (Power BI)

## 📌 Project Overview

This project is an interactive employee analytics dashboard developed in Microsoft Power BI. The dashboard analyses workforce data to provide insights into employee demographics, job satisfaction, education, and attrition.

The project demonstrates the use of Power Query for data cleaning, DAX calculations, and interactive dashboard design.

---

## 🎯 Objectives

- Analyse employee demographics.
- Monitor employee attrition.
- Measure employee job satisfaction.
- Explore education levels and qualifications.
- Build an interactive dashboard for HR decision-making.
